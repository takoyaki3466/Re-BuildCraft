# Re-BuildCraft

## 概要

Re-BuildCraft は、Minecraft の BuildCraft 関連機能を再実装し、その仕組みや動作を現代の Minecraft 環境で再現することを目的としたプロジェクトです。

本プロジェクトでは、既存の機能や動作を参考にしながら、各機能の実装、動作の検証、不具合の修正を進めています。

## 不具合の報告

不具合を発見した場合は、GitHub Issues から報告してください。

報告の際は、原因の調査と再現を容易にするため、可能な限り以下の情報を記載してください。

- Minecraft のバージョン
- 使用している Mod Loader とそのバージョン
- Re-BuildCraft のバージョン
- 関連する Mod や依存関係
- 不具合の発生条件と再現手順
- クラッシュレポートやログ
- 必要に応じてスクリーンショットや動画

報告する前に、同様の問題がすでに報告されていないか確認してください。また、他の Mod との競合が疑われる場合は、可能であれば導入する Mod を最小限にした環境でも動作を確認してください。

開発途中のビルドについては、正式リリース版と動作が異なる場合があります。使用したビルドの種類や取得元についても、必要に応じて記載してください。

## 開発への参加

Re-BuildCraft の改善につながる不具合修正やコードの改善などの貢献を歓迎します。

変更を提案する場合は、GitHub の Pull Requests からプルリクエストを送信してください。変更の目的、実装内容、既存機能への影響を明確にし、可能な限り動作確認の結果を添付してください。

大規模な機能追加や仕様変更については、実装を開始する前に Issue などを通じて相談することを推奨します。事前に方針を共有することで、既存の設計との整合性を確保し、重複した作業を防ぐことができます。

また、フォーマットの変更だけを目的とした修正は避け、可読性、保守性、動作の正確性などに実質的な改善をもたらす変更を行ってください。

## ビルド方法

ソースコードからビルドする場合は、事前に Git および本プロジェクトが要求する Java 開発環境を用意してください。

基本的な手順は以下のとおりです。

1. Re-BuildCraft のリポジトリをクローンする。
2. プロジェクトのルートディレクトリへ移動する。
3. Gradle の設定ファイルを確認し、必要な Java バージョンや依存関係を準備する。
4. Gradle Wrapper を使用してビルドを実行する。

Gradle Wrapper と `build` タスクが利用できる場合は、次のコマンドでビルドできます。

Linux / macOS:

```bash
./gradlew build
```

Windows:

```bat
gradlew.bat build
```

ビルド成果物は、通常、各モジュールの `build/libs` ディレクトリに生成されます。実際の出力先やビルド手順は、プロジェクトの構成に従ってください。

Minecraft、Mod Loader、および関連 Mod のバージョンによって、利用できる機能や動作が異なる場合があります。

導入や開発を行う際は、対象バージョンと依存関係を確認してください。対応バージョンや外部向け API の仕様については、プロジェクト内の設定ファイルおよび関連ドキュメントを参照してください。

## おわりに

Re-BuildCraft は、既存の機能の再現と改善を通じて、BuildCraft に関連する仕組みを新しい環境で利用できるようにすることを目指しています。
